# desktop-dock

一款面向 Windows 11 的桌面美化工具，以接近 macOS 风格的 Dock 为核心，优先保证流畅度与可恢复性。

> 当前处于规划阶段，尚未实现应用功能，也没有可下载的安装包。下面列出的功能均为开发计划。

## 计划功能

- 居中悬浮 Dock、半透明背景、连续悬停放大与点击反馈。
- 隐藏和恢复桌面图标，保留原有桌面文件。
- 固定应用、拖拽添加与排序、启动应用和切换窗口。
- 运行状态提示、可选自动隐藏、设置界面与托盘入口。
- 后续逐步加入多窗口预览、文件夹和回收站入口。

Windows 原生任务栏由用户自行设置。高开销视觉效果和附加功能将提供独立开关，并在原型中验证性能。

## 开发方向

- 首期目标：Windows 11 x64，先完善单个显示器上的体验和常见显示缩放适配。
- 拟采用 C#、.NET 10、WPF 和 Windows 系统接口；Dock 渲染方案将在原型验证后确定。
- 开发分为技术原型、核心体验、扩展功能和稳定性打包四个阶段。

参见 [开发路线](docs/ROADMAP.md)。
