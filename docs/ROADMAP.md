# 开发路线

## 产品范围

面向 Windows 11 的个人桌面美化工具，以流畅的 macOS 风格 Dock 为核心。保留 Windows 桌面和原有文件；桌面图标的隐藏状态需要能够恢复。原生任务栏的位置由用户设置，顶部隐藏和玻璃增强可选启用。

本路线已由用户批准进入开发。先提交规划，再依次完成可运行原型、核心体验、扩展功能和稳定性打包。技术选型和默认效果根据原型实测调整。

完整规格见 [产品与实施计划](PLAN.md)，每个版本的实际完成情况以更新记录为准。

## 阶段一：技术原型（0.1.0-preview.23 已实现，持续验收）

- 验证透明背景、毛玻璃、圆角、阴影及正确的鼠标点击区域。
- 验证连续悬停放大和鼠标快速移入移出时的动画表现。
- 验证 Dock 不抢输入焦点，桌面图标能够隐藏并恢复。
- 记录帧时间、CPU、GPU 和内存占用，据此确定渲染方案。

交付目标：可运行的技术验证原型及测试结论；该阶段不代表日常功能完整。

当前已有可构建源码、可运行预览和打包脚本，已完成跨进程命中、最大化 / 全屏避让与恢复检查。详见 [验证记录](VALIDATION.md)。实际 GPU 呈现帧率、功耗和广泛硬件兼容仍待验证。

preview.3 按新要求移除启动动效和窗口定位，以实际遮挡隐藏、全局召回和应用图标最小化 / 恢复为当前交互方案。

preview.4 按后续确认增加主屏顶部原生任务栏增强：隐藏 / 边缘唤出、工作区释放、可选独立玻璃组件、关闭恢复和进程异常退出保护。默认关闭，不改变任务栏位置；这是原生任务栏增强，并非新建顶部菜单栏。

preview.5 修复任务栏收放导致最大化窗口尺寸变化的问题：保持原生窗口可见标记，用透明度控制呈现；唤出时只调整任务栏叠放。增加保持窗口存活并反复收放的尺寸事件与命中检查，以及高 DPI 恢复检查。

## 阶段二：核心体验（拟 v0.2.0）

preview.6 已加入快捷方式拖入、拖动排序和拖远松手移除，替换为底边停留唤出并取消全局召回快捷键。使用透明图标和半高倒影，绘制窗口与动态输入区域分离；右键菜单交互期间保持显示。顶部任务栏增加短暂收放过渡，继续保持已有窗口尺寸稳定。完整桌面视觉与更多程序兼容性仍持续验收。

preview.7 修复拖拽初始化中途收到取消或鼠标捕获变化时的越界退出，移除拖动开始时的强制前台切换，并增加同步原生消息回归。

preview.8 增加 Dock 上滑淡入 / 下滑淡出与反向过渡，动画结束停止更新；应用点击使用按下时的活动窗口判断最小化 / 恢复，并验证完整图标点击消息路径。

preview.9 修复只有进程包标识的桌面应用关联，以及 AppsFolder 参数被误判为独立文档入口的问题。未运行应用改为双击启动，单击不启动；已运行应用仍为单击切换。

preview.10 增加应用图标右键关闭窗口和退出应用。先请求正常关闭；保存 / 取消窗口仍可见时交还应用，后台驻留时由用户确认是否结束匹配的进程。保留 Explorer、桌面和任务栏排除规则。

preview.11 按用户要求取消“退出应用…”及后台进程结束功能，保留右键关闭窗口与从 Dock 移除。

preview.12 修复普通点击和双击时悬停放大被中断的问题；实际进入拖拽后才收回放大。点击增加独立的轻微按压 / 回弹反馈，倒影同步变化，布局和点击区域保持稳定；增加双击各阶段布局与视觉变换检查。

preview.13 修复隐藏的顶部任务栏在原占用区域内被普通点击误唤出的问题。顶边检测限制在主屏最顶部两物理像素，悬停 / 点击保持按当前露出高度计算；保留菜单交互、工作区稳定和恢复保护。

preview.14 修复 Chromium 浏览器快捷方式的启动来源参数阻止已有窗口复用的问题；支持浏览器先于 Dock 打开时直接切换，按完整可执行文件路径区分同名安装，保留网址、指定配置及独立网页应用入口语义。

preview.15 增加运行小圆点与活动蓝色短线，配合淡圆角背景提示；最小化后保留运行标记，设置窗口同样适用。状态由窗口事件合并更新，Dock 隐藏时延后扫描，过渡完成停止动画；保持透明图标和半高倒影。

preview.16 按新要求将状态标记改成蓝色横线，活动时加长；加入最右侧桌面面板及虚拟分组、浅色时间 / 日历 / 天气桌面组件和品牌图标。天气采用城市选择、低频刷新和本地缓存；Windows 设置使用稳定应用标识切换与收起。

preview.17 修正为运行白线 / 活动蓝线，排除隐藏后台窗口和 Explorer 辅助窗口，移除图标背景板。桌面入口移至最左侧，设置界面改为浅色分栏，并使用透明背景 Logo。

preview.18 将桌面面板与时间 / 天气组件改为玻璃材质，增加面板悬停缩放、滚轮翻页与预设自动分类。时钟显示秒数，移除日历；拖远移除入口时显示红色垃圾桶提示。

preview.19 修复 Explorer 普通鼠标捕获被误作拖拽而唤出 Dock，实际拖动接近 Dock 才提前显示；按新要求将桌面面板与组件改成不模糊、无边框的透明样式。

preview.20 完成内部整理：分离检查代码、复用界面资源、缓存静态布局、减少命中区域临时分配，并统一原子写入与版本来源；保留现有功能和视觉交互。

preview.21 加入透明窗口预览与多窗口选择，悬停延迟打开，点击精确切换，滚轮 / 按钮翻页；使用系统 DWM 合成，按页注册、收起释放，保留现有图标点击、拖拽与自动隐藏规则。

preview.22 参考原生任务栏预览，改用不透明浅灰卡片与深色标题，精简公共标题区；每张卡片在标题或缩略图上悬停时独立变亮并突出边线，不缩放布局或重建缩略图。单窗口省略分页空间，桌面面板和组件样式不变。

preview.23 加入当前用户登录自启、低频检查 Releases、下载安装包并校验、显式运行安装向导；提供当前用户安装、覆盖升级、卸载、便携包、中文说明与标签触发的发布流程。安装与更新保留用户配置，发布前验证实际运行与恢复。

- 固定应用、拖拽添加与排序、名称提示。
- 启动应用、运行标记与窗口切换。
- 自动隐藏、全屏避让、位置和底部间距调节。
- 基础设置、托盘入口和配置保存。

## 阶段三：扩展功能

- 多窗口预览与切换。
- 文件夹面板、回收站入口与状态。
- 主题、透明度、动画强度与性能模式。
- 根据实测结果决定默认开启的功能；组件按需加载。

## 阶段四：稳定性与打包（目标 v1.0.0）

- 检查全屏、锁屏、休眠唤醒、资源管理器重启和显示缩放变化。
- 检查正常退出与异常结束后的桌面图标恢复路径。
- 检查与 Windows 原生任务栏唤出区域的交互。
- 准备 Windows 可运行包、使用说明、恢复说明与更新记录。

## 验证目标

首期以 Windows 11 x64、一个可选择的显示器和常见显示缩放为范围。约 20 个 Dock 图标的场景以稳定 60 FPS 为初步目标；空闲时避免持续重绘和忙轮询。CPU 和内存指标在原型阶段实测并记录，不作为已经实现的承诺。

完整多屏 Dock、顶部菜单栏、动态壁纸和系统窗口动画改造暂不列入首期范围。
