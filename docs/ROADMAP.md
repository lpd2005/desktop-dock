# 开发路线

## 产品范围

面向 Windows 11 的个人桌面美化工具，以流畅的 macOS 风格 Dock 为核心。保留 Windows 桌面和原有文件；桌面图标的隐藏状态需要能够恢复。原生任务栏的位置由用户设置，顶部隐藏和玻璃增强可选启用。

本路线已由用户批准进入开发。先提交规划，再依次完成可运行原型、核心体验、扩展功能和稳定性打包。技术选型和默认效果根据原型实测调整。

完整规格见 [产品与实施计划](PLAN.md)，每个版本的实际完成情况以更新记录为准。

## 阶段一：技术原型（0.1.0-preview.6 已实现，持续验收）

- 验证透明背景、毛玻璃、圆角、阴影及正确的鼠标点击区域。
- 验证连续悬停放大和鼠标快速移入移出时的动画表现。
- 验证 Dock 不抢输入焦点，桌面图标能够隐藏并恢复。
- 记录帧时间、CPU、GPU 和内存占用，据此确定渲染方案。

交付目标：可运行的技术验证原型及测试结论；该阶段不代表日常功能完整。

当前已有可构建源码、可运行预览和打包脚本，已完成跨进程命中、最大化 / 全屏避让与恢复检查。详见 [验证记录](VALIDATION.md)。实际 GPU 呈现帧率、功耗和广泛硬件兼容仍待验证。

preview.3 按新要求移除启动动效和窗口定位，以实际遮挡隐藏、全局召回和应用图标最小化 / 恢复为当前交互方案。

preview.4 按后续确认增加主屏顶部原生任务栏增强：隐藏 / 边缘唤出、工作区释放、可选独立玻璃组件、关闭恢复和进程异常退出保护。默认关闭，不改变任务栏位置；这是原生任务栏增强，并非新建顶部菜单栏。

preview.5 修复任务栏收放导致最大化窗口尺寸变化的问题：保持原生窗口可见标记，用透明度控制呈现；唤出时只调整任务栏叠放。增加保持窗口存活并反复收放的尺寸事件与命中检查，以及高 DPI 恢复检查。

## 阶段二：核心体验（拟 v0.2.0）

preview.6 已加入快捷方式拖入、拖动排序和拖远松手移除，替换为底边停留唤出并取消全局召回快捷键。使用透明图标和半高倒影，绘制窗口与动态输入区域分离；右键菜单交互期间保持显示。顶部任务栏增加短暂收放过渡，继续保持已有窗口尺寸稳定。完整桌面视觉与更多程序兼容性仍持续验收。

- 固定应用、拖拽添加与排序、名称提示。
- 启动应用、运行标记与窗口切换。
- 自动隐藏、全屏避让、位置和底部间距调节。
- 基础设置、托盘入口和配置保存。

## 阶段三：扩展功能

- 多窗口预览与切换。
- 文件夹面板、回收站入口与状态。
- 主题、透明度、动画强度与性能模式。
- 根据实测结果决定默认开启的功能；组件按需加载。

## 阶段四：稳定性与打包（目标 v1.0.0）

- 检查全屏、锁屏、休眠唤醒、资源管理器重启和显示缩放变化。
- 检查正常退出与异常结束后的桌面图标恢复路径。
- 检查与 Windows 原生任务栏唤出区域的交互。
- 准备 Windows 可运行包、使用说明、恢复说明与更新记录。

## 验证目标

首期以 Windows 11 x64、一个可选择的显示器和常见显示缩放为范围。约 20 个 Dock 图标的场景以稳定 60 FPS 为初步目标；空闲时避免持续重绘和忙轮询。CPU 和内存指标在原型阶段实测并记录，不作为已经实现的承诺。

完整多屏 Dock、顶部菜单栏、动态壁纸和系统窗口动画改造暂不列入首期范围。
