## 当前资源采样

20 个图标、反复打开设置并解析快捷方式后的短时样本：

| 指标 | 样本 |
| --- | --- |
| 应用更新间隔中位数 | 8.51 ms |
| 应用更新间隔 P95 | 16.04 ms |
| 工作集 | 约 185.0 MiB |
| 5 秒空闲 CPU 增量 | 低于计数分辨率 |

更新间隔不是 GPU 实际呈现帧率；低于计数分辨率不代表零开销。该样本加载了设置控件与快捷方式解析组件，也不代表仅启动 Dock 时的基线或长期平均。移除启动动效不等于整体内存必然下降。

保留的动画只用于悬停变化，稳定后停止；没有外部窗口截图流或额外启动动效。窗口事件触发遮挡检查，低频计时器负责超时与状态回退。

## 顶部原生任务栏回归

直接运行最终自包含 EXE，在当前主屏顶部原生任务栏上完成 18 项检查：

- 独立恢复进程就绪后才开始改变任务栏。
- 实际任务栏可以隐藏，位置保持不变，顶部预留工作区被释放。
- 新建最大化测试窗口可以使用释放出的屏幕顶部。
- 控制边缘停留状态后，实际任务栏显示；模拟菜单状态时保持显示。
- 切换状态不唤出任务栏；手动唤出及三秒超时通过。
- 官方玻璃进程运行并完成窗口初始化；停止增强后受管理副本退出。
- 原可见状态、工作区及恢复记录清理通过。
- 子进程调用 Environment.Exit 绕过 Dispose / finally 直接结束；独立恢复进程仍恢复任务栏、工作区并清理玻璃进程。

边缘与菜单自动测试通过受控状态输入触发产品逻辑，没有移动用户鼠标、注入快捷键或点击其他应用。玻璃初始化检查本身不验证像素；另通过系统截图工具的实际屏幕预览确认顶部任务栏有半透明模糊背景。检查用截图未进入仓库和运行包；没有做与 macOS 的像素级对照或主观流畅度量化。

任务栏独立回归程序（未加载 Dock 图形渲染）在启用隐藏与玻璃时的 3 秒短样本：

| 进程 | 工作集 | 归一化空闲 CPU 增量 |
| --- | --- | --- |
| 任务栏检查宿主 | 约 52.5 MiB | 约 0.06% |
| 玻璃组件 | 约 68.1 MiB | 低于计数分辨率 |
| 独立恢复进程 | 约 29.7 MiB | 低于计数分辨率 |

玻璃与恢复进程合计约增加 98 MiB 常驻工作集；这不代表把它与另一轮 Dock 样本相加就能得到精确的总内存。关闭玻璃时不启动玻璃进程；关闭任务栏增强时不保留上述两个后台进程。CPU 短样本不等于长期平均或零开销，DWM 的 GPU 和电源成本尚未测量。

## 测试方法与边界

独立进程打开测试窗口。遮挡测试显式选择这些测试窗口，避免移动或最小化用户正在使用的其他应用。生产模式检查实际可见应用窗口。

后台激活测试中，测试子进程通过 Windows 官方 AllowSetForegroundWindow 协作接口允许其父测试进程恢复焦点；生产模式不对其他应用使用该接口。

Alt+Tab 自动回归验证真实窗口样式和切换状态序列，没有向其他应用注入 Alt+Tab，也没有完成所有系统切换器视觉路径的人工验收。

EXE 和快捷方式代表性检查已完成；特殊启动器、完整多窗口选择、部分 Store 应用、权限受限窗口、游戏独占全屏、多显示器、混合刷新率、资源管理器重启及长期运行仍需继续验证。任务栏增强当前只验证此构建的主屏顶部任务栏；第三方任务栏工具、真实开始 / 搜索 / 通知面板的全部交互路径和系统升级兼容性仍需继续验收。

## 可复现命令

先构建，再运行：

```powershell
dotnet run --project tests/DesktopDock.Checks -c Release
dotnet run --project src/DesktopDock.App -c Release -- --smoke-test --stress --data-dir artifacts/regression
dotnet run --project src/DesktopDock.App -c Release -- --verify-recovery --data-dir artifacts/recovery
dotnet run --project src/DesktopDock.App -c Release -- --taskbar-test --data-dir artifacts/taskbar-regression
```

冒烟测试会打开自己的普通、遮挡、最大化和全屏测试窗口，不隐藏桌面图标。恢复往返检查暂时隐藏图标后恢复原状态。数据位于忽略目录，不随源码或运行包分发。

任务栏回归要求主屏任务栏已在顶部，且玻璃组件已通过 scripts/Prepare-TaskbarGlass.ps1 准备。该检查会暂时隐藏和显示真实任务栏、调整工作区、打开一个最大化测试窗口，然后恢复；包含独立子进程非正常清理退出的保护检查。
