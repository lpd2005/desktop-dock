## 动画调度修订前后

同一台机器、20 个图标、模拟连续横向悬停：

| 调度 | 更新间隔中位数 | 更新间隔 P95 |
| --- | --- | --- |
| WPF Rendering 回调 | 31.99 ms | 34.54 ms |
| 活跃高精度计时器 | 8.39 ms | 16.67 ms |
| 自包含 exe 完整回归 | 8.76 ms | 19.52 ms |
| 减少空闲窗口调用后的复查 | 8.36 ms | 16.96 ms |

修订后的短时空闲采样工作集约 139.4 MiB；5 秒采样中 CPU 时间增量低于计数分辨率。之前另一轮约 0.13%。这不是零开销承诺，也不是长期平均值。

最终自包含运行包的独立检查工作集约 150.2 MiB，5 秒空闲 CPU 平均约 0.26%。静止时 3543 个外部采样点、放大时 3455 个外部采样点均没有被 Dock 阻挡；最大化、全屏及恢复检查通过。短时采样会随系统负载变化。

减少空闲时重复显示窗口的调用后，候选包复查工作集约 145.7 MiB、空闲 CPU 约 0.13%；静止 / 放大中的区域检查、最大化、全屏及恢复再次通过。

这些间隔是应用更新回调的节奏，不是 GPU 实际呈现帧率；尚未完成 PresentMon / ETW 呈现分析、GPU 与功耗采样及不同显示器刷新率的全面验证。

## 可复现命令

先构建，再运行：

```powershell
dotnet run --project tests/DesktopDock.Checks -c Release
dotnet run --project src/DesktopDock.App -c Release -- --smoke-test --stress --data-dir artifacts/regression
dotnet run --project src/DesktopDock.App -c Release -- --verify-recovery --data-dir artifacts/recovery
```

冒烟测试会短暂打开自己的普通、最大化及全屏测试窗口；不隐藏桌面图标。恢复往返检查会暂时隐藏图标后恢复原状态。诊断数据仅位于忽略目录，不随源码上传。

## 仍需验证

长期运行、异常强制终止后的完整恢复、多种显示缩放、远程桌面、资源管理器重启、游戏独占全屏与不同 GPU、混合刷新率及省电模式。真实画面和主观流畅度需要继续验收，当前不声称已复刻 macOS Dock。
