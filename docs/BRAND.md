# 品牌图标

黄橙双波图形由项目所有者提供。白色外部背景使用内置 `image_gen` 工具移除，保留内部浅色曲线；透明 PNG 重新编码后生成 Windows 多尺寸 ICO。资源位于 `src/DesktopDock.App/Assets/Brand.png` 和 `Brand.ico`，不记录原始文件路径。

最终编辑提示词：

> Use case: background-extraction. Edit target: the supplied yellow-orange double-wave W-shaped application logo. Remove ONLY the exterior white/off-white background surrounding the logo and replace it with genuine fully transparent alpha. Keep the logo itself exactly unchanged: the dark brown outer outline, yellow upper wave, orange-red lower wave, internal cream/white curved stripe, gradients, shape, proportions, and layout. In particular the pale cream stripe INSIDE the dark brown outlined logo must remain opaque and intact. No redesign, no new edges, no drop shadow, no white matte/halo or rectangular plate. Maintain clean anti-aliased cutout edges for a Windows application icon. Output transparent PNG, square canvas, centered, same scale and padding as the reference.
