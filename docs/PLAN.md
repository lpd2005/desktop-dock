# 产品与实施计划

## 已确认需求

- Windows 11 个人使用，优先保证流畅度和低后台占用。
- 保留 Windows 桌面与壁纸，隐藏桌面图标，底部显示 macOS 风格的居中悬浮 Dock。
- 半透明毛玻璃、圆角、柔和阴影、连续悬停放大和自然回落动画。
- Windows 原生任务栏由用户自行设置，程序不更改其隐藏设置。
- 性能允许时尽量丰富功能，附加效果按需加载并提供独立开关。
- 首期 Windows 11 x64，在一个显示器上显示 Dock，适配常见缩放。

## 功能及优先级

| 范围 | 功能 | 实施方式 |
| --- | --- | --- |
| 技术原型 | 半透明背景、真实背景模糊、圆角、阴影、连续悬停放大 | 先验证透明、动画、命中区域和占用；不支持模糊时使用半透明底色 |
| 桌面管理 | 隐藏、临时显示、恢复桌面图标 | 只改变显示状态；保存原状态；提供异常退出后的恢复命令 |
| 应用管理 | 固定、拖拽添加及排序、移除、提示名称 | 图标异步读取并缓存，配置仅在本机保存 |
| 启动与切换 | 启动应用、显示运行标记、切换窗口 | 系统接口与窗口事件；不在每一帧扫描进程 |
| 自动隐藏 | 可选隐藏、延迟唤出、全屏避让 | 与任务栏唤出区域实测；底部间距可调 |
| 窗口预览 | 悬停展示缩略图、多个窗口切换 | 优先 DWM，离开释放；不可预览时使用标题与图标 |
| 文件入口 | 文件夹、回收站及其状态 | 内容展开时才读取 |
| 设置与托盘 | 图标大小、放大、主题、透明度、位置、性能模式、可选开机启动 | 设置即时预览、本机保存；明确退出与恢复入口 |
| 后续组件 | 天气等 | 核心性能达标后再增加，默认关闭，低频刷新 |

## 架构方向

- C#、.NET 10 LTS；设置界面使用 WPF。
- Dock 采用独立 Win32 窗口承载 Windows.UI.Composition，使用系统合成动画。
- Shell、Win32、DWM 完成图标提取、应用启动、窗口识别与背景合成。
- 将几何布局、动画目标、配置和系统集成拆开，使核心逻辑可独立验证。
- 主窗口不夺取输入焦点；可交互区域之外保持点击穿透；弹出设置时才激活设置窗口。
- 配置、图标缓存和诊断数据仅保存在本机用户数据目录，不进入仓库或发布包。

渲染实现必须先验证背景模糊、透明角落、点击穿透、拖拽和缩放兼容性，不能仅根据框架宣传判断流畅度。

## 开发顺序与阶段成果

### v0.1.0：技术原型

建立可构建的解决方案，完成透明 Dock、图标和连续放大、基本启动入口、桌面图标隐藏恢复及托盘退出。验证鼠标命中、不抢焦点、空闲不持续重绘，交付可运行包和实测结论。基础配置和恢复能力可以提前实现，以便安全试用。

### v0.2.0：核心日用体验

固定应用、拖拽添加排序、运行状态与窗口切换、自动隐藏、全屏避让、设置保存。支持资源管理器重启、显示缩放及显示器变化后恢复布局。

### 后续功能版本：扩展

多窗口预览、文件夹面板、回收站、主题与性能模式。逐项比较开启前后的占用和帧时间，再决定默认配置。

### v1.0.0：稳定性与分发

完成锁屏、休眠、资源管理器重启、显示变化、任务栏冲突、异常结束恢复和长期运行检查；准备完整运行包、使用说明及恢复说明。

## 验收与性能预算

- 以目标电脑约 20 个图标为测试场景，60 Hz 下以稳定 60 FPS 为初步目标，高刷新率另行验证。
- 空闲 CPU 平均低于 1%，基础模式工作集争取不超过 150 MB。记录测试环境、采样时长和工具；不把未经测量的目标写成结果。
- 同时检查应用与桌面合成相关的开销，避免把 CPU 工作转到 GPU 后声称零开销。
- 鼠标快速扫过、频繁移入移出和启动应用时，动画无明显跳变，输入不被阻塞。
- 隐藏时停止不必要更新；扫描、图标解码、文件夹读取不阻塞界面。
- 正常退出恢复原图标显示状态。异常结束后支持恢复命令或下次启动恢复；保留原桌面文件。
- 仅通过构建不算实际运行通过；手工场景、自动检查、未验证项目分别记录。

## 暂缓范围

完整多屏 Dock、顶部菜单栏、动态壁纸、系统窗口动画改造、商业付费、自动更新服务。
