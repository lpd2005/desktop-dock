# 产品与实施原则

更新日期：2026-10-31。当前源码开发版为 **0.1.0-preview.24（未发布）**，公开可安装测试版仍为 **0.1.0-preview.23**。项目已经进入持续迭代；原先的技术原型、核心交互和分发能力已有实现。本页维护产品约束与技术原则，待办顺序以 [ROADMAP.md](ROADMAP.md) 为准。

## 当前产品范围

- Windows 11 22H2 或更新版本，x64；首期以主显示器为范围，优先保证流畅度、低后台占用和可恢复性。
- 保留 Windows 桌面、壁纸和原有文件，按设置隐藏桌面图标，以透明的底部 Dock 提供应用入口。
- Dock 无包围底板和描边，图标保留原轮廓；提供半高渐淡倒影、连续悬停放大和轻微按压反馈。桌面面板和时间 / 天气组件也采用透明样式；窗口预览使用不透明卡片。
- 原生任务栏的位置由用户的系统环境设置；软件可选增强已位于主屏顶部的任务栏，提供隐藏、过渡、玻璃和恢复，默认关闭，不擅自更改系统自动隐藏偏好。
- 附加能力按需加载，支持关闭；已有减少动画选项。先测量占用与帧时间，再决定是否扩展效果或增加性能档位。
- 配置、缓存和诊断留在本机；天气使用手动城市，软件更新来自本仓库公开 Releases，不请求设备自动定位。

## 已实现的能力与边界

| 范围 | 当前实现 | 不应混同的后续能力 |
| --- | --- | --- |
| 桌面管理 | 隐藏 / 恢复图标、桌面面板、搜索、分类、虚拟分组 | 不移动桌面文件，不是文件管理器替代品 |
| 应用管理 | 固定、拖入、排序、拖远移除、名称提示与右键操作 | 不强制结束应用后台进程 |
| 启动与切换 | 未运行双击启动，运行单击切换 / 最小化，运行状态标记 | 特殊启动器与权限差异仍需验证 |
| 自动隐藏 | 遮挡隐藏、底边停留唤出、平滑收放、自身设置 / 菜单保护 | 不再注册全局召回快捷键 |
| 窗口预览 | DWM 实时缩略图、分页、独立高亮、点击精确激活 | 不持续截图，不把浏览器标签页当作独立窗口 |
| 文件入口 | 打开文件夹与回收站 | Dock 内文件夹内容展开、回收站状态自动刷新尚待实现 |
| 桌面组件 | 秒钟、日期文字、手动城市天气与缓存 | 没有独立日历组件，暂不新增更多常驻组件 |
| 设置与分发 | 即时保存、托盘、自启开关、安装 / 卸载、版本检查与校验下载 | 自动检查不等于静默下载 / 安装；尚未发布稳定版 |
| 关于与帮助 | 源码开发版已加入设置中的品牌、版本、项目与帮助入口 | 公开 preview.23 尚不包含关于页，等待后续运行包发布 |
| 显示适配 | 主屏布局、显示 / 工作区 / DPI 变化处理 | 不代表已完成完整多屏和所有唤醒 / 热插拔场景验收 |

## 架构与实现原则

- C# / .NET 10，设置与面板使用 WPF；独立 Win32 窗口承载 Windows.UI.Composition / DirectComposition 与图形资源。
- 绘制窗口与可交互输入区域分离，透明空白区域不阻挡其他应用；普通 Dock 交互不抢焦点，设置页按需激活。
- 几何布局、动画目标、配置与系统集成拆分，核心规则可独立检查。窗口预览交给 DWM 合成，Shell / Win32 接口处理图标、入口与窗口身份。
- 优先复用事件与缓存，合并重复消息；动画稳定后停止高频提交，图标解码、网络和内容读取不阻塞界面。
- 配置已有规范化与临时文件替换写入；后续补齐最近有效备份和可理解的错误恢复，不能把默认值回退当成完整的数据保护。
- 新功能先定义对点击、隐藏、拖拽和恢复的影响；只修改自己的窗口与明确接管的任务栏状态，不移动、缩放或猜测关闭其他应用。
- 正常退出和卸载恢复桌面状态；系统环境改变时遵守恢复保护，不覆盖其他程序新设的工作区。

## 验收与性能预算

- 约 20 个图标、60 Hz 下以稳定 60 FPS 为初步目标，高刷新率另行验证；实际呈现帧率不能用应用更新间隔代替。
- 基础模式空闲 CPU 平均低于 1%，工作集争取不超过 150 MB；这些是目标，尚无统一当前版本性能基线。观察值、历史短样本与目标分别标注。
- 同时记录 Dock、辅助玻璃 / 恢复进程与 DWM 的开销，不能只看主进程并声称总成本很低；测量方法见 [ROADMAP.md](ROADMAP.md)。
- 快速扫过图标、移入 / 移出、连续点击、拖入 / 排序 / 取消、窗口预览与自动隐藏均应保持输入可用，透明区域没有额外拦截。
- 锁屏 / 解锁、休眠 / 唤醒、Explorer 重启、缩放与主屏变化按场景验收；已有消息处理或模拟检查不等于这些实机路径都已通过。
- 仅通过构建不算运行验收。历史检查结果保留在 [VALIDATION.md](VALIDATION.md)，新增结论应注明版本、条件、方法和局限，不公开个人数据。
- 应用变更按风险运行相关检查；纯文档变更检查事实、链接和差异即可，不把未运行的测试写成通过。

## 后续开发与暂缓范围

下一轮先处理配置 / 启动可靠性、补齐生命周期验收和性能基线，再完善显示变化处理；文件夹展开、回收站状态和配置导入 / 导出依次作为候选扩展。具体任务和完成标准统一在 [ROADMAP.md](ROADMAP.md) 维护。

完整多屏、新建顶部菜单栏、动态壁纸引擎、系统窗口动画改造和后台自动安装服务暂缓。软件内检查 / 校验下载 / 用户主动运行安装向导已经实现，不再列为未开发功能。
