# 内部整理记录

本次通读 src、tests、scripts 中的项目代码及构建配置。整理以 preview.19 的功能、透明样式、动画参数、点击 / 拖拽语义和配置格式为基准，未新增产品功能。

| 范围 | 检查与处理 |
| --- | --- |
| 程序入口、控制器 | Program 只保留启动流程；Controller 管理生命周期；检查驱动移到 Controller.Checks，保留业务方法和调用次序。合并重复的自动检查模式判定；回归驱动取得测试窗口焦点后再断言活动状态。 |
| Dock 主窗口 | 回归方法移到 DockWindow.Checks；静态布局按图标数、尺寸、放大倍率、可用宽度和分隔位置缓存。动态悬停布局与动画算法保持原样。 |
| 界面与图像 | 复用同一按钮、开关、滑块、滚动条模板；冻结的品牌图像按需加载一次。模板依旧为每个控件创建独立视觉树和状态。 |
| 输入区域 | 用有名称的矩形字段替代数字下标，常规尺寸使用栈上缓冲；保留坐标取整、边界扩展、区域合并、命中与所有权规则。 |
| 配置、天气、恢复 | AtomicJson 只统一原有的序列化、写入 .tmp、替换文件三步；各调用点保留目录创建、JSON 格式、异常处理和恢复策略。 |
| 桌面目录、搜索与分组 | 搜索词只裁剪一次，筛选顺序和规则保持不变；不改变分组数据或原文件。 |
| 应用识别、浏览器与协议 | 审阅目标解析、窗口绑定、可见性和进程标识缓存；保留已有兼容分支和排除规则。 |
| 合成、动效、原生接口 | 审阅资源释放、图标复用、计时器和 COM / Win32 边界；保留独立输入 / 呈现窗口、倒影、按压与状态动效。移除一处未使用的窗口样式读取。 |
| 原生任务栏与守护进程 | 保留工作区、透明度、唤出与异常恢复流程；原子写入复用后仍由原调用点管理恢复记录。 |
| 核心算法与检查 | 保留现有几何、弹簧、可见性、点击、拖拽、分页及边界检查，增加布局缓存失效与模板状态独立性检查。 |
| 构建与分发 | 打包文件名、界面版本和检查报告共用项目版本来源；保留依赖版本、组件校验、许可证和隐私检查。 |

没有把外观相似但职责不同的 Dock / 任务栏状态机、普通配置与恢复记录、普通应用与浏览器识别强行合并。这些差异承担已有行为和兼容性。旧配置字段也继续保留。

验证结果见 [VALIDATION.md](VALIDATION.md)。布局缓存命中时减少分配并不代表已量化 GPU 帧率、整机功耗或所有硬件的性能提升。
