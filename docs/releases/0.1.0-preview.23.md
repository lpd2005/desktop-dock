# Desktop Dock 0.1.0-preview.23

首次提供可安装的 Windows 测试版。支持 Windows 11 22H2 或更新版本、x64、主显示器。

## 下载

- 推荐：`DesktopDock-0.1.0-preview.23-Setup-x64.exe`，提供当前用户安装、开始菜单入口及卸载。
- 便携版：`DesktopDock-0.1.0-preview.23-win-x64.zip`，请完整解压后运行 `DesktopDock.exe`。
- `UserGuide.txt`：中文版安装、常用操作、开机自启、更新及恢复说明。
- `SHA256SUMS.txt`：安装包和便携包校验值。

两个运行包都自带 .NET，无需额外安装运行时。

## 新增

- 设置新增“启动与更新”，可启用当前用户登录后自启；兼容登录时资源管理器尚未就绪的情况。
- 检查 GitHub Releases、显示版本说明、下载进度、取消和重试，以及下载大小 / SHA-256 校验。
- 用户确认后启动安装向导，升级保留现有固定应用、分组、组件和其他设置。
- 自动更新检查每天最多一次，可关闭；不会自动下载或安装。
- 保留透明 Dock、半高倒影、窗口预览、点击切换、拖拽、桌面面板、小组件和可恢复的顶部任务栏增强。

## 说明

这是测试版，完整多屏、ARM64 及所有第三方任务栏工具组合尚未验证。
安装包暂未签名，Windows 可能显示发布者未知；请核对本仓库的发布来源。
自启默认关闭，安装后在“启动与更新”中开启。顶部任务栏增强也默认关闭。
正常退出或卸载会恢复桌面状态；卸载保留用户配置。

反馈：https://github.com/lpd2005/desktop-dock/issues
