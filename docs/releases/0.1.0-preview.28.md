# Desktop Dock 0.1.0-preview.28

Windows 11 桌面 Dock 预览版，支持 Windows 11 22H2 或更新版本、x64、主显示器。本次汇集 preview.24–preview.28 的开发变化，可从 preview.23 升级。

## 下载与更新

- 推荐：`DesktopDock-0.1.0-preview.28-Setup-x64.exe`，提供当前用户安装、开始菜单入口与卸载；覆盖安装保留用户配置。
- 便携版：`DesktopDock-0.1.0-preview.28-win-x64.zip`，完整解压后运行 `DesktopDock.exe`。
- `UserGuide.txt`：中文版使用说明。
- `SHA256SUMS.txt`：安装包与便携包的 SHA-256 校验值。

两个运行包都自带 .NET，无需额外安装运行时。已使用测试版的用户可在“设置 → 启动与更新”中检查并下载安装；下载完成后仍需主动运行安装向导，不静默安装。

## 应用提醒

- 新增“外观与动画 → 应用消息提醒”，默认开启。
- 已固定的应用请求 Windows 任务栏闪烁时，Dock 短暂显示约 3 秒，对应图标显示柔和的红色背景脉动；点击图标、预览或切换到应用后清除。
- 隐藏或暂停时停止脉动；减少动画使用静态红色背景。保持原有透明图标与白色 / 蓝色运行状态横线。
- 不读取聊天内容或未读数量。仅改变托盘图标、未向系统请求闪烁的应用可能无法识别；各版本 QQ / 微信的实际消息兼容性仍需继续验证。

## 可靠性与设置

- 修复息屏恢复后顶部原生任务栏增强被重复显示通知误停用的问题；增加独立的显示器电源状态处理。
- 显示 / DPI / 工作区变化合并后重新定位，锁屏与休眠期间暂停交互和组件，恢复时清理过期的拖拽与预览。
- 增加有效配置备份、损坏原件归档、确认恢复、保存失败提示和重试；修复便携长路径导致设置入口失败的问题。
- 设置新增“关于”，提供品牌、版本、帮助与更新入口。

## 性能

- 减少应用身份缓存命中的临时闭包分配，设置窗口复用已解码的冻结图标。
- 完成 10 / 20 / 40 个固定入口各至少 10 分钟的基础采样。20 入口对照样本的托管分配率约下降 14%，总工作集未降低；不把该结果作为所有硬件的性能承诺。
- 增加隔离采样入口与脚本。完整口径及待完成项目见 [性能记录](https://github.com/lpd2005/desktop-dock/blob/main/docs/PERFORMANCE.md)。

## 范围与说明

这是预览版。完整多屏、ARM64、所有第三方任务栏组合、真实系统生命周期与长期性能验收尚未完成。原生任务栏增强默认关闭，任务栏位置仍由用户的系统环境设置。

安装包暂未签名，Windows 可能显示“未知发布者”。正常退出与卸载会恢复桌面状态；卸载保留用户配置。
