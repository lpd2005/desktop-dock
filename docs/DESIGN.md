# Dock 交互与当前实现

当前源码以 0.1.0-preview.25 为准，公开测试版仍为 0.1.0-preview.23。preview.2 的启动动效和窗口位置调整已按用户要求移除。

## 配置与自启的错误恢复

自启命令无效或超过系统登记长度时，自启设置对象保留不可用原因，页面只禁用自启开关；其他设置与更新入口继续使用。登记仍遵循 [Windows Run 键的命令长度限制](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)，不为绕过限制添加服务或计划任务。

配置保存先验证现有主文件，正常写入通过同目录临时文件与 [File.Replace](https://learn.microsoft.com/en-us/dotnet/api/system.io.file.replace?view=net-10.0) 保留上一份有效配置；首次保存同时创建有效备份。主文件损坏或缺失、备份存在时，不把它当成首次运行重新填充入口。

读取失败后只临时显示备份或默认值，设置页提供“确认恢复并保存”。确认前不覆盖文件，也不按临时配置改变桌面图标或任务栏；确认后先归档损坏原件，再写入当前配置，有效旧备份不会被损坏内容替换。文件占用或只读等保存错误显示“更改尚未保存”和重试入口，不通过未处理异常退出程序。其他模块的原子 JSON / 恢复日志协议保持原样。

## 设置中的关于页

“关于”位于设置侧栏最后一项，保留原有页面顺序。使用现有浅色卡片与按钮样式，展示品牌、完整程序集版本、简介、支持平台、项目与帮助入口，以及隐私和第三方组件说明；不会标注尚未确定的项目许可证。

“检查更新”只切换到已有的“启动与更新”页面，由原有流程负责检查；项目链接由用户点击后交给默认浏览器，失败时在页内显示提示。页面自身没有网络请求、计时器或持续动画，小窗口通过现有滚动容器访问完整内容。可用 `--about` 启动并直接打开此页。

## 显示、遮挡与召回

使用可见、未最小化且未被系统隐藏的应用窗口边界，检查是否与 Dock 的静止底座区域重叠。普通窗口也能触发隐藏；不要求窗口最大化。桌面、原生任务栏、Dock 设置及自身对话框、菜单与提示不作为应用遮挡；通过窗口所属进程识别自身界面，不按窗口标题匹配。其他应用覆盖时仍照常隐藏。主显示器以外的窗口不相交时不影响 Dock。

窗口事件触发遮挡状态更新，低频计时器处理召回超时和状态回退。Dock 隐藏时停止动画，不占用整条屏幕底边；没有遮挡时仍保留可选的普通自动隐藏。

拖入成功后，显示保护从拖拽交接到最新一轮图标加载，直到新布局完成后短暂保持约 350 ms；连续拖入时，较早的加载完成不会解除较新的保护。切换应用时仍抑制显示。遮挡稳定性与召回计时在拖拽期间持续推进，避免松手后重新触发稳定等待而隐藏 / 重现。

新增入口复用现有图标、倒影和图形资源，只为新目标准备资源；新画面先完成布局再接入，移除旧入口时先保留仍在使用的画面。正常更新不清空整排图标。加载期间保留原显示区域，新布局完成后再更新对应的原生输入区域，Dock 外不增加鼠标拦截。

取消全局召回快捷键。鼠标在主屏物理底边两像素内停留约 180 ms 后唤出；停在底边、图标区域或菜单中保持显示，离开约 750 ms 后收起。没有应用遮挡且关闭普通自动隐藏时保持常显。底边检测只读鼠标位置，隐藏时不留输入窗口或透明触发条。切换应用时清除本次唤出并重新等待底边停留，避免闪现；窗口遮挡消失后仍等待约 250 ms 稳定状态。

绘制窗口由独立原生 HWND 承载，图标布局更新时保持尺寸与位置，不设置动态窗口区域。它使用分层透明输入穿透样式；动态区域仅应用到不承载图像的输入 HWND，避免 SetWindowRgn 触发绘制宿主的窗口位置 / 裁剪更新。先前仅检查隐藏状态会漏掉这种画面重置，现增加实际呈现像素检查。依据：[SetWindowRgn](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowrgn)、[分层窗口命中](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features#layered-windows)。

收放阶段整体移动自身窗口约 28 DIP 并改变透明度：显示约 220 ms 上滑淡入，隐藏约 180 ms 下滑淡出。反向请求从当前位置继续，动画结束后停止高频更新。隐藏开始便释放鼠标输入，显示就位后恢复输入窗口；透明空白区域不阻挡其他应用。切换任务时直接收起以避免切换器闪现，“减少动画”同样采用即时切换。不截图外部应用，也不移动外部应用窗口。

右键菜单使用由输入窗口持有的原生菜单。菜单的完整交互生命周期计入显示保护，不受覆盖和离开延迟关闭；选择、取消或切换应用后退出。参见 [TrackPopupMenuEx](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-trackpopupmenuex)。

拖动排序保持原有大小，用独立浮动图标跟随鼠标。距离静止 Dock 区域约 80 DIP 后图标变淡，松手从 Dock 移除入口；Esc、丢失捕获或其他取消操作保留入口。原快捷方式与文件不移动、不删除。排序拖动不主动切换前台，按下期间只读鼠标位置，补足快速移出窗口的跟踪。初始化保存条目、列表版本和本次按下版本；取消、捕获丢失或新的按下使旧初始化失效，尚未接入的浮动图标随即释放。

## 应用图标的任务栏语义

固定应用的悬停在约 400 ms 后展开窗口预览；无可识别窗口和内置入口继续显示原名称提示。一个应用的普通窗口按原有身份匹配，带独立参数的入口仍限于其已关联窗口。每页最多四个，页数随工作区与 DPI 变化；不把浏览器标签页当作独立窗口。图标到预览之间保留约 350 ms 离开宽限，不增加屏幕空白区域的鼠标窗口。停在预览中计入 Dock 交互，避免自动隐藏。

预览参考 [Windows 原生任务栏的窗口预览](https://blogs.windows.com/windows-insider/2024/07/12/announcing-windows-11-insider-preview-build-22635-3930-beta-channel/)，主体使用不透明浅灰底、深色标题、圆角和柔和阴影；仅圆角外部与阴影保留透明度，不模糊或透出后方内容。每个窗口独立显示图标、标题和缩略图，省略重复的应用公共标题，仅在多页时显示底部导航。

鼠标经过卡片标题、空隙或原生缩略图时，合并鼠标消息并按实际命中位置选择唯一卡片，约 120 ms 内变亮并显示细高亮边线。原生缩略图单独报告鼠标移动 / 离开，避免 WPF 跨 HWND 时丢失反馈。高亮只更新现有画刷，不重建 DWM 关系、不改变卡片尺寸与位置；没有持续轮询或高亮空闲动画。减少动画即时切换。

预览使用无激活工具窗口，每个可见缩略图由独立、受控大小的原生顶层窗口承载。通过 [DwmRegisterThumbnail](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmregisterthumbnail) 建立关系，以 [DwmUpdateThumbnailProperties](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmupdatethumbnailproperties) 设置等比内容与透明度。系统负责图像更新，不运行截图循环。只有显示时每秒刷新窗口列表、标题和内容尺寸；仅当前页注册关系，关闭或翻页释放。160 / 100 ms 淡入淡出结束即停止专用动画时钟，减少动画时直接切换。

点击缩略图前重新验证窗口、所属进程和应用关联；仅激活 / 恢复选中窗口，不使用图标的再次点击最小化语义。最小化窗口可能显示系统缓存，注册失败时使用可点击图标和标题。Esc、Alt+Tab、图标按下、拖拽、菜单、设置变更与 Dock 收起立即撤销预览；自身预览窗口不触发遮挡检测。窗口标题与内容只用于当前本机展示，不写入配置、日志或仓库。

参考 [Apple 的 Dock 说明](https://support.apple.com/zh-cn/guide/mac-help/mchlp1119/mac) 的运行状态区分，并按当前要求增强可见性：运行应用使用约 10 DIP 白色短线，仅当前活动应用使用约 22 DIP 蓝色长线。不添加图标背景板、色板或遮罩；倒影仍为原图标的半高镜像。状态以约 140 ms 渐变，跟随排序，拖起源图标时一起隐藏，不改变布局与输入区域。“减少动画”立即切换状态，稳定后停止动画时钟。

窗口枚举复用应用启动的身份匹配，只统计可见或最小化窗口，排除隐藏 / 系统隐藏的窗口、桌面与任务栏。Explorer 还须为文件浏览窗口类，辅助进程窗口不产生运行标记。运行状态与活动状态分别计算；同一应用多个窗口时任一窗口活动即使用蓝线。独立参数入口只认已经关联的窗口，Dock 设置单独读取自身窗口生命周期。只有后台进程、没有可识别窗口的应用不显示标记。

复用现有窗口事件和可见性计时器，变化最多约每 150 ms 合并一次；Dock 显示时以 2 秒间隔回退校正，隐藏时延后扫描到下次显示。不增加常驻高频刷新、后台线程或进程全量扫描。每次扫描共享进程名、路径与应用身份读取缓存，结束后丢弃，避免 PID 重用后保留旧身份。

- 没有可匹配窗口：单击不启动，双击启动。
- 目标窗口当前活动且没有最小化：再次点击最小化。
- 目标窗口已最小化：恢复。
- 目标窗口在后台：激活。
- 右键菜单的打开操作只打开 / 激活，不最小化。
- Dock 设置保留单击打开和再次点击最小化。

双击匹配同一入口、Windows 的双击时间及距离范围；拖拽、取消、图标更新或右键菜单会清除上一点击。普通按下和原生 WM_LBUTTONDBLCLK 路径均可完成第二次点击。识别不使用常驻计时器，也不延迟已运行应用的单击响应；应用启动后的短暂识别期间阻止重复启动，后续单击不会中止窗口关联。

普通点击不改变悬停放大的目标。鼠标仍停在图标上时，按下、松开、两次点击之间和第二次松开后保持同一放大波形；移开鼠标时正常收回。按下但未移动到拖拽阈值时仍保留放大，实际开始拖拽才切到原始大小及浮动图标。松开后的静止悬停继续停止动画调度，不为双击等待额外运行计时器。

点击反馈独立于悬停布局：图标在当前大小上向底部中心轻缩至约 94%，完整按压约 70 ms、松开回弹约 140 ms；倒影保持接触面并同步缩放。只改变图像视觉变换，不重新排列邻居或缩小命中区域。连续点击从当前进度平滑反向，各图标分别保存反馈状态，快速切换目标不重置其他图标的回弹。复用现有动画时钟和图像缓存，回弹完成后停止调度；拖拽、隐藏及取消交互清理按压状态。“减少动画”关闭反馈。

活动窗口取鼠标按下时的根窗口快照，松开时使用同一快照作点击判断。点击过程中出现焦点变化时，仍按最初点击的活动状态决定最小化；取消的按下会清除快照。Dock 设置图标使用相同语义。

EXE、快捷方式目标、应用 URI、应用标识和本次启动窗口用于关联图标。商店桌面应用优先使用系统进程包标识，无包身份时读取窗口的显式应用标识；只有进程标识的窗口也可关联。AppsFolder 的应用标识参数表示应用身份，不作为独立文档参数；不回退到操作所有 Explorer 窗口。链接只读取目标信息，不修改原快捷方式；窗口关联只保存在当前进程内。文件夹、URL 和其他带参数的入口优先使用本次启动后关联的窗口，避免泛化到无关窗口。

Chromium 浏览器入口仅带 `--source-shortcut-location` 启动来源标记时，按普通应用识别已有窗口，无需先由 Dock 启动。直接 EXE 和快捷方式解析后采用相同分类；完整路径避免将另一安装目录中的同名浏览器当成目标。网址、指定配置目录、独立网页应用、隐私模式、新窗口及未知参数仍保留独立入口语义，不从中猜测无关窗口。上游将该标记用于启动统计，并在普通快捷方式分类中排除它，参见 [Chromium 开关定义](https://chromium.googlesource.com/chromium/src/+/main/chrome/common/chrome_switches.h) 和 [快捷方式分类](https://chromium.googlesource.com/chromium/src/+/main/chrome/browser/profiles/profile_shortcut_manager_win.cc)。

多窗口应用点击图标时处理活动或最近关联的窗口；悬停后已经可以在缩略图卡片中选择指定窗口。自定义启动代理、权限受限程序和特殊窗口需要继续兼容验证。无法可靠识别时保留双击启动，不猜测操作其他应用。

通过 ShowWindowAsync 最小化 / 恢复，保留应用内容；应用启动和切换不关闭或移动外部窗口。只有主动选择“关闭窗口”时才请求关闭对应窗口。用户主动开启的任务栏增强管理原生任务栏及其顶部预留工作区。

依据：[ShowWindowAsync](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-showwindowasync)、[AppUserModel.ID](https://learn.microsoft.com/en-us/windows/win32/properties/props-system-appusermodel-id)、[GetApplicationUserModelId](https://learn.microsoft.com/en-us/windows/win32/api/appmodel/nf-appmodel-getapplicationusermodelid)、[GetDoubleClickTime](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getdoubleclicktime)。

## 右键关闭窗口

应用图标提供“关闭窗口”和“从 Dock 移除”。关闭窗口处理当前活动或最近关联窗口，通过 WM_CLOSE 交给应用自己的保存 / 取消逻辑。未运行或无法关联窗口时置灰。按用户要求已删除“退出应用…”菜单、后台结束确认、进程枚举和强制结束实现；应用自身的托盘退出行为由应用管理。

普通 EXE / 快捷方式通过完整路径校验已匹配窗口，商店应用使用应用标识；带文档参数的入口优先使用本次已关联的窗口。发出关闭消息前再次核对窗口和 PID。桌面、任务栏和 Dock 自身不作为外部窗口关闭目标。

依据：[WM_CLOSE](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-close)。

## Alt+Tab 闪现修复

旧预览为了便于截图曾使用 WS_EX_APPWINDOW，导致 Dock 进入任务切换列表；切换中又可能短暂判定应当显示。

当前正式运行与安全预览均固定使用 WS_EX_TOOLWINDOW、WS_EX_NOACTIVATE，不设置 WS_EX_APPWINDOW。设置也是工具窗口，不进入任务栏或 Alt+Tab。切换期间抑制显示，并等待稳定状态再显示，避免前台中间状态造成闪现。

自动回归检查窗口样式和切换状态序列；不向用户其他应用注入 Alt+Tab。真实切换器的全部视觉路径仍需要继续验收。

依据：[Extended Window Styles](https://learn.microsoft.com/en-us/windows/win32/winmsg/extended-window-styles)。

## 保留的视觉与性能策略

Dock 不绘制包围底板或描边，不给图标添加白底、色板或圆角背景。保留图标原轮廓与比例，将透明留白整理到统一基线；完整镜像倒影保持宽度、高度压缩为 50%，向下渐淡。倒影只在图标加载时生成并缓存。图形和输入区域使用相同布局，输入窗口之外可与其他应用交互。动画仅在悬停、点击、拖动或状态变化期间更新，稳定后停止；不修改系统全局计时器分辨率。

已经移除启动弹跳、设置淡入 / 位移动效、外部窗口尺寸和位置调整，相关设置与代码也删除。不会持续捕获外部窗口，也没有灯神展开的截图合成层。启动后的窗口绑定只短时跟踪，识别后停止，最长 5 秒；运行标记采用上述窗口事件和低频校正。

更新间隔指标代表应用提交节奏，不等于 GPU 实际呈现帧率；不能仅凭低 CPU 占用声称达到 macOS 的流畅度。

## 桌面面板与小组件

交互参考 [Apple Launchpad](https://support.apple.com/en-ie/guide/mac-mini/aside/apd2d2a58738/2024/mac/15) 的搜索、网格与分组，以及 [Mac 桌面小组件](https://support.apple.com/zh-cn/guide/mac-help/mchl52be5da5/27/mac/27) 的卡片、拖动和独立移除。桌面面板只整理当前用户 / 公共桌面与常用系统入口，不扫描个人文档或修改原文件。分组仅保存目标路径的本地索引，单击打开原入口，右键可固定到 Dock；搜索和分页在本地完成。九宫格固定在最左侧，设置固定在最右侧；两个入口均不参与排序或拖远移除，拖入位置与排序索引单独限定在中间的固定应用范围。

面板与组件按新要求取消液态玻璃和系统亚克力背景，使用 WPF 分层窗口逐像素透明合成。整个容器为统一深色透明遮罩，默认 alpha 64 / 255，组件深色选项为 104 / 255；没有模糊、渐变高光或边框，背后的内容保持原样透出。文字使用冻结并共享的轻微阴影，便于在复杂背景上阅读；图标不添加背景板，不调整整个窗口的不透明度来实现样式。

Shell 拖入唤出分为两个条件：先确认实际指针移动超过拖拽阈值或收到显式拖拽通知，再确认指针进入 Dock 附近。Explorer 捕获鼠标只用于识别可能的来源，不单独代表拖拽；普通点击、轻微抖动、远处框选 / 滚动均不提前召回。进入 Dock 附近后保留显示直到释放或取消，继续由原生 OLE 目标决定能否固定。底边停留唤出保持原有规则。

面板保留约 170 / 110 ms 淡入 / 淡出、中途反向及 Esc 收起。图标悬停在原命中区域内缩放至 115%，按下轻缩；动画完成不继续调度，减少动画时即时切换。滚轮仅在图标区域翻页，累计精细输入并对连续触控板输入节流；侧栏仍可正常滚动。页码到边界不重建图标，并置灰翻页按钮。预设分类依据扩展名、目录和系统入口，加载时后台计算并缓存，不读文件内容、不修改手动分组。

图标异步加载并缓存，完成时只修改对应图像，不重建正在交互的按钮。组件为独立非置顶、非激活工具窗口，前台变化时整理到普通应用下方，不拦截桌面其他位置；拖动位置按工作区保存并限制在当前屏幕内。

时间改为 `HH:mm:ss`，低优先级定时器每秒读取本地时间并只更新数字，日期仅跨日更新，数字采用等宽排列；停用时钟时停止秒定时器。移除日历 UI、开关、位置与月历算法，旧配置自动忽略。天气使用 Open-Meteo 公开接口，中文地名优先查市级名称，展示解析地区；每 30 分钟更新并支持手动重试，30 分钟内的缓存可复用。城市、分组、位置与天气缓存只保存在本机。无数据时不填充示例值；失败时展示上次成功数据和时间或暂不可用。参考 [天气接口](https://open-meteo.com/en/docs)、[地名接口](https://open-meteo.com/en/docs/geocoding-api)。

拖出 Dock 的移除手势参考 [Apple Dock](https://support.apple.com/en-gb/guide/mac-help/mh35859/26/mac/26)：达到现有移除距离后才在浮动图标右下角显示红色垃圾桶，拖回立即清除，取消不移除。普通 / 待移除两张位图在手势开始时生成，越过边界时只更新已有浮动窗口的位图，不新增输入窗口、不按帧绘制垃圾桶。松手仅删除 Dock 入口。

Windows 设置的 URI、Explorer 快捷方式及包入口统一按应用标识识别，避免将激活协议误作独立窗口；沿用异步最小化与还原，保留已有窗口切换。标识依据 [Microsoft 的 AUMID 说明](https://learn.microsoft.com/en-us/windows/configuration/store/find-aumid)。程序、托盘和设置使用用户提供的品牌图，重新编码并生成多尺寸 ICO，不包含原图路径或源文件元数据。

## 顶部原生任务栏增强


顶边触发限主屏最顶部两物理像素；隐藏进度为零时，任务栏原矩形内的普通点击不属于唤出交互。悬停 / 点击保持按当前收放进度计算已露出的高度，取整方式与上滑图层相同；过渡期间鼠标进入已露出部分可继续保持显示，未露出部分不触发反向唤出。开始、搜索、托盘等显式 Shell 交互和手动召回保持原有规则。此修复仅调整输入条件，不改变任务栏或外部窗口的尺寸与工作区。

默认关闭，仅在用户已将主屏原生任务栏置顶时启用。不改位置、注册表或系统自动隐藏偏好，不注入鼠标 / 键盘输入。120 ms 低频检查鼠标位置与交互状态；顶边停留 180 ms 显示、离开 750 ms 隐藏，Alt+Tab 期间抑制边缘触发。原生开始、搜索与托盘菜单操作时保持显示。检测只读鼠标位置，没有顶部输入窗口。

preview.4 使用 ShowWindow 收放任务栏，会使 Explorer 重新预留顶部空间。即使随后把工作区改回去，已经缩小的最大化窗口仍可能保留空白。preview.5 保留原生任务栏的 WS_VISIBLE 标记，通过 WS_EX_LAYERED 和 SetLayeredWindowAttributes 的整体透明度切换呈现：隐藏时 alpha 为零，唤出时恢复原值，并只调整任务栏叠放以出现在全屏应用上方。不移动任务栏，不调用 SWP_SHOWWINDOW，不调整其他应用窗口；隐藏后的输入穿透与唤出后的可交互性由真实命中检查验证。

如果系统已经启用原生自动隐藏，则让 Windows 自己处理显示。只释放确认属于该顶部任务栏的预留区域，启用时临时调用 SPI_SETWORKAREA，不写入系统偏好。收放路径不改变工作区。Explorer 或玻璃组件初始化可能重新预留原来的条带，因此以一秒回退检查协调；只认本次记录的原始区域与展开区域，其他工作区更改会使增强停止。不会移动、重新最大化用户已经打开的窗口。

变更前原子写入恢复记录，并启动一个等待父进程退出的独立恢复进程。记录包含当前任务栏窗口、进程启动时间、原工作区、透明度与叠放状态，仅在本机保存。正常关闭恢复后通知守护进程退出；异常结束则由它恢复。保留其他窗口样式，只恢复本次改变的部分；仍可读取旧版恢复记录。恢复和读取几何时显式使用物理像素坐标，避免没有启动 WPF 的 dotnet 托管守护进程在 150% 缩放下使用虚拟化坐标。资源管理器、任务栏位置或显示器改变时恢复并暂停，避免将旧几何应用到新环境。

玻璃使用未修改的 TranslucentTB 2026.2 官方便携程序，独立运行，不将其代码链接入 Dock。固定下载 SHA-256，分发原许可证、同版本源码及来源说明，运行前验证组件文件哈希。运行副本和配置位于本机应用数据目录。检测到已有实例时不修改其配置或停止它；只清理本软件数据目录中由本软件管理的副本。

该组件会通过自己的 Explorer XAML 集成设置背景，并负责外观恢复。关闭玻璃、关闭增强或退出时停止受管理副本；守护进程也覆盖父进程在启动副本后尚未完成 PID 记录就退出的短暂间隙。任务视图和节电状态交还系统外观。系统更新可能改变兼容性，因此 UI 展示组件状态，允许分别停用隐藏与玻璃。
